# SARV A Risc-V
<p align="center">
  <img src="docs/assets/logo.png" alt="SARV32 Core Logo" width="800">
</p>

**SARV** is a 32-bit RISC-V core implementation supporting the RV32I base integer instruction set with multiple extensions. Designed for embedded systems.

---

## ✨ Features

| Feature | Support |
| :--- | :--- |
| **Base ISA** | RV32I |
| **Compressed** | C (16-bit instructions) |
| **Bit Manipulation** | B (Zba, Zbb, Zbs) |
| **Integer Multiplication** | Zmmul  |
| **Conditional Operations** | Zicond |
| **Control Status Registers** | Zicsr |
| **Performance Counters** | Zihpm |
| **Pause Hint** | Zihintpause |
| **Interrupts** | Machine Timer, Machine External, Machine Software |
